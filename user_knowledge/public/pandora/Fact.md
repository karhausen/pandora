# Fact

Pandora ist ein lokaler, modularer KI-Assistent mit kontrollierter Agentenarchitektur. Der Core ist die Schaltzentrale: Er nimmt Aufgaben an, entscheidet über Routing, nutzt LLMs, Tools, Skills und Memory, schützt sensible Daten und erzeugt nachvollziehbare Vorschläge für Wachstum.

## Stand: 

### Pandora – Projekt-Prompt (Stand: MVP 25.1.3) 

### Projektvision 

Pandora ist ein autonomer, lokaler KI-Agent in Python. 

Nicht das LLM ist Pandora. 

Das LLM ist nur ein Werkzeug. 

Pandora selbst besteht aus einem stabilen Core, der Wissen verwaltet, denkt, plant, lernt und kontrolliert handelt. 

Der Core muss langfristig unabhängig von einzelnen LLMs sein. 

LLMs können ausgetauscht werden, ohne dass sich die Architektur ändert. 

Pandora soll sich kontrolliert weiterentwickeln. 

Keine unkontrollierte Selbstmodifikation. 

Alle Änderungen müssen nachvollziehbar, testbar und freigabepflichtig sein. 


# Architekturprinzip 

Pandora besteht künftig aus drei Ebenen. 

## 1. System Brain (deterministisch) 

Python. 

Verantwortlich für: 

- Workflow 
- Security 
- Policies 
- Filesystem 
- Governance 
- Release Management 
- State Machines 
- Scheduler 
- Action Engine 

Hier wird kein LLM benötigt. 

## 2. Cognitive Brain (LLM) 

Dies ist die eigentliche Intelligenz. 

### Aufgaben: 

- Reasoning 
- Priorisierung 
- Zielbildung 
- Strategien 
- Zusammenfassungen 
- Reviews 
- Empfehlungen 
- Kontextbewertung 

Das LLM entscheidet niemals direkt.
Es erzeugt ausschließlich Empfehlungen. 

## 3. Execution Brain 

Python.
### Verantwortlich für: 

Planner 
Worker 
Tool-Ausführung 
Skills 
APIs 
Automatisierung 

### Grundprinzip
Python sammelt Fakten.
LLM denkt.
Python handelt.

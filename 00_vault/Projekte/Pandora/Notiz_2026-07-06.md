# Pandora – Aktueller Stand (MVP 30.8)

## Ziel

Pandora ist ein lokaler KI-Assistent.

Nicht das LLM ist Pandora.

Das LLM ist ausschließlich die kognitive Instanz.

Pandora (Python) orchestriert den gesamten Ablauf.

---

# Architektur

```text
User
   │
   ▼
Prompt Builder
   │
   ▼
LLM
   │
   ▼
Action
   │
   ▼
Router (Dispatcher)
   │
   ├── Vault
   ├── Memory
   ├── (später: Tools)
   ├── (später: Skills)
   ├── (später: Workflows)
   ▼
Context Builder
   │
   ▼
LLM
   │
   ▼
Antwort
   │
   ▼
User
```

---

# Grundprinzip

- Python entscheidet nicht fachlich.
- Der Router entscheidet nicht fachlich.
- Das LLM entscheidet, welche Aktion benötigt wird.
- Python validiert und führt aus.

---

# Aktive Komponenten

- Prompt Builder
- LLM Conversation Loop
- Route Registry
- Router (Dispatcher)
- Vault Search
- Memory Search
- Context Builder

---

# Deaktiviert

- Tool-Ausführung
- Skills
- Capability Gap
- Tool Factory
- Evolution
- Planner / Worker

Diese Komponenten werden erst wieder aktiviert, wenn die Basis stabil ist.

---
